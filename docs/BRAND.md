## Brand Positioning

Inzly is a modern SaaS platform that helps real estate agents deeply understand homes and confidently guide clients through showings.
The brand should feel intelligent, grounded, calm, and trustworthy.
Avoid flashy, salesy, or gimmicky visuals. Inzly should feel like an expert advisor, not a marketing tool.

## Core Brand Attributes

Smart, not technical
Confident, not loud
Professional, not corporate
Warm, not playful
Modern, not trendy

## Design Philosophy

Design should feel quiet and intentional.
Whitespace is a feature, not empty space.
Clarity beats decoration.
Every element should help the user understand a home better.

## Color Palette

Primary Color:
Deep Slate Blue – #1F2A33
Used for headers, navigation, primary buttons, and key UI anchors. Feels intelligent and grounded.

Secondary Color:
Soft Sage Green – #8FAEA3
Used sparingly for highlights, badges, success states, and secondary actions. Evokes homes, structure, and calm confidence.

Accent Color:
Warm Clay – #C47A5A
Used very sparingly for call-to-action emphasis, icons, or important insights. Should never dominate.

Neutrals:
Off White – #F7F8F6 (main background)
Light Stone – #E5E7E4 (cards, dividers)
Mid Gray – #8A8F93 (secondary text)
Charcoal – #2B2F33 (primary body text)

Avoid pure black or stark white. Everything should feel softened and human.

## Typography

Primary Font (UI + Headings):
Inter or Source Sans 3
Clean, readable, modern, neutral.

Secondary Font (Optional for Headings or Emphasis):
DM Sans or Manrope
Only use if contrast is needed. Keep it subtle.

Typography Rules:
Use sentence case, not all caps.
Headings should feel calm and confident, not oversized.
Body text should prioritize readability over style.
Line height should feel generous.

## Iconography

Use thin, rounded line icons.
Icons should be simple and functional, never decorative.
Avoid filled or heavy icons.
Icons should support understanding, not draw attention to themselves.

## Layout & Spacing

Use a card-based layout for information sections.
Cards should have soft corners and subtle shadows.
Spacing should feel breathable and intentional.
Avoid dense layouts or information overload.

Buttons should be rounded rectangles, not pills.
Primary actions should be clear but not aggressive.

## UI Tone & Microcopy

Language should feel like a knowledgeable guide standing next to you during a showing.

Examples of preferred tone:
“Here’s what matters about this system.”
“Common questions buyers ask about this feature.”
“Why this detail is worth pointing out.”

Avoid hype words like:
Game-changing
Revolutionary
Crushing it
Dominate

Use calm authority instead.

## Navigation

Navigation should be minimal and intuitive.
Users should never feel lost or overwhelmed.
Prefer clear labels over clever wording.

Example sections:
Homes
Insights
Systems
Notes
Client View

## Client-facing vs agent-facing UI

Agent UI can feel slightly more technical and detailed.
Client-facing views should be simplified, reassuring, and educational.
Client views should never feel overwhelming or jargon-heavy.

## Accessibility

Ensure high contrast for text readability.
Buttons and interactive elements should be clearly identifiable.
Design should work equally well on desktop and tablet.

## Overall Feel Check

If the UI feels like:
A calm expert
A trusted advisor
Someone who knows homes deeply and explains them clearly

You are doing it right.

If it feels flashy, busy, or salesy, pull it back.
